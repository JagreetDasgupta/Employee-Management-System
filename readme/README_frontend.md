# Employee Management System - Frontend

A modern, responsive React frontend for the Employee Management System.

## 🚀 Features
- Modern UI/UX (Tailwind CSS, Lucide React)
- Responsive design
- Authentication (JWT)
- Role-based access (Admin, HR)
- Dashboard with charts
- Employee CRUD
- **Advanced filtering (search, department, position)**
- **Export employees as CSV/JSON (with filters)**
- Real-time notifications
- Form validation
- Loading states

## New Features
- **Position filter dropdown** for employees
- **Export**: Download filtered employees as CSV or JSON

## Setup
1. `cd frontend`
2. `npm install`
3. Create `.env` and set `REACT_APP_API_URL` if backend is not on localhost:3000
4. `npm start`
